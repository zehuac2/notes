# Cloud Hosting

- Disable: “Permissions > Block all public access”
- Enable: “Properties > Static website hosting”
- Update bucket policy to enable public read access

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PublicReadGetObject",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::zc2616-assignment1/*"
    }
  ]
}
```
