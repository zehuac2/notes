# Concepts

- **Level**: a scene
- **Transform**: positional and rotational information
- **Actor**: Anything that can be placed in the level is an actor
  - Each actor has a Transform
- **Components**: special objects that can be attached to actors (ex.
  `UStaticMesh`)
